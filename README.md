# CatSite

Ласкаво просимо до проекту сайту про котика Лева та його господаря Вову.

## Опис

Це невеликий односторінковий сайт для презентації дружби між котом Левом і його господарем Вовою. На сторінці є:

- головний банер з фото;
- історія їхньої дружби;
- секція з характером Лева;
- галерея з фото;
- адаптивний дизайн для мобільних пристроїв.

## Технології

- HTML
- CSS
- JavaScript

## Як запустити локально

1. Завантажте або відкрийте папку проекту.
2. Відкрийте файл `index.html` у браузері.
3. Для локального сервера можна також запустити простий HTTP-сервер, наприклад:

```bash
python -m http.server 8000
```

Після цього відкрийте в браузері:

```text
http://localhost:8000
```
